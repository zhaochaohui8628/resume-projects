# 「参数」标注口径（定稿版，专项微调数据构建依据）

> 目的：让「参数」专项训练数据的正确性**可审计** —— 口径写死、词表经人工逐条核验，
> 标注由「已核验词表 + 口径规则」机械生成，任何人可按本文复算出同一份标注。
>
> 口径以黄金测试集 `gold_test`（543 句 / 92 个参数实体）为对齐基准：**专项数据必须对齐
> 权威测试集口径**，自造 dev 指标（与训练同源）不能作为判断依据。

## 1. 实体定义

`参数` = 施工方案中**被规定、被测量、被控制的量化指标**（量名或规格值）。
与其它 5 类的边界：不是 `设备`（塔吊/钢丝绳）、不是 `工序`（开挖/浇筑）、不是 `工程类型`（基坑/地墙）；
`规范编号` 走正则，不属参数。

## 2. 标注形态（仅两类）

| 形态 | 触发条件 | 例 |
|---|---|---|
| **A 量名** | `core_nouns` 词表内的**具体指标名词**单独出现（gold_test 92 个参数中 79 个是裸量名） | `施工荷载`、`混凝土强度`、`桩长`、`跨度`、`垂直度`、`坍落度`、`步距`、`锚固长度`、`壁厚`、`起重量`、`报警值`、`允许偏差` |
| **SPEC 规格值** | 无量名依附的规格/等级值（仅 ∅ 径规格 / C\d{2} 强度等级 / 抗渗 P 等级） | `∅800@600`、`C35`、`P8` |

**明确不标注的形态**（对齐 gold_test 实证）：
- **量名+紧邻值不合并**：gold 为分离标注（`安全间距≥500mm` → `安全间距` 与 `500mm` 两个实体；`桩长60m` 只标 `桩长`）。
- **无「数字+单位」独立值规则**：只有 ∅ 径规格 / C35 / P8 这类封闭规格值才标；普通 `1700mm`/`60.6m`/`100%` 不标。

## 3. 泛化量名一律不裸标

以下**泛化量名**在 `reject_words` 中（裸标必 FP，gold_test 实证不认可）：
`荷载/厚度/高度/深度/速度/间距/直径/系数/半径/压力/温度/沉降/变形/轴力/力矩/标高/埋深/
孔深/井深/强度等级/长度/宽度/距离/墙厚/幅宽/压强/跨度…`（完整见 `data/phase6/param_lexicon.json`）。

判别准则：**具体指标名词**（施工荷载、混凝土强度、桩长、锚固长度、开挖面积、额定起重量…）
可裸标；**泛化量名**只有带上具体定语形成公认指标（如 `开挖深度`、`保护层厚度`、`安全间距`）才在词表内。

## 4. 不得标为参数（硬负样本来源）

日期与时间点、编号与序号（`附图001`/`表6.3`/方案编号/第X章）、轴号与楼层（`A7 轴`/`2F`/`地下三层`）、
规范编号（`GB50010-2010`/`建质〔2009〕87号`）、孤立单位或符号（`mm`/`%`）、构件计数（`3 根`/`5 块`/`2 台`/`10 组`）、
泛化量名无值语境（`荷载大小`/`温度较高`/`速度应一致`/`厚度均匀`）、仅作构词成分（`预应力`/`剪力墙`/`大体积`/`需要系数`）。

## 5. 实证结果（gold_test 543）

| 模型 | 参数类严格 F1 | 整体严格 F1 |
|---|---|---|
| s2_crf_stage2（未专项） | 0.632 | 0.8849 |
| **s2_crf_param_v3（专项定稿）** | **0.714（+8.2pt）** | **0.9055（+2.1pt）** |

六类实体全不降；参数类仍为六类最低（0.714），后续迭代方向：补 gold 认可裸量名词表缺口、
限值语境独立值正例。
